# Janhit Group Main

This is the main group portal frontend application for Janhit Education Group.

## Standardized Structure

This application conforms to the standard monorepo folder structure:

- `src/assets/`: Media assets and images
- `src/components/`: Shared React UI components
- `src/contexts/`: React context providers
- `src/hooks/`: Custom React hooks
- `src/layouts/`: Common page layout components
- `src/pages/`: Section components
- `src/routes/`: Route components (using TanStack Router)
- `src/services/`: Future API integrations
- `src/styles/`: Global stylesheets
- `src/types/`: TypeScript definitions
- `src/utils/`: Common helpers

## Commands

Run these from the monorepo root:

- Development: `npm run dev:main`
- Build: `npm run build:main`
